# 老板键 BossKey

一个通用老板键小工具。目标是：选中任意窗口后，按一下全局快捷键就能立刻把它藏起来，再按一下恢复。

## 使用方法

1. 双击运行 `BossKey.exe`。
2. 点“拾取窗口”，屏幕出现十字光标后再点一下要隐藏的窗口（例如游戏窗口），Esc 可取消。
3. 点“录制快捷键”，直接按下想用的组合键，例如 `Ctrl+Alt+F10`。
4. 默认“完全隐藏”，也可以改成“最小化”或“移到屏幕外”。

之后无论游戏是否在前台，按下刚才设置的快捷键即可隐藏 / 恢复。

## 附带功能

- 隐藏后本程序自动缩到托盘，避免被发现。
- 可选“老板键时同时隐藏托盘图标”，连托盘也一起藏起来，再按快捷键恢复。
- 如果连老板键都忘了，重新双击运行 BossKey.exe 会把隐藏中的程序界面和托盘唤回（不会自动弹出目标窗口）。
- 可防止目标窗口被系统或程序自己重新弹出。
- 记住上次目标窗口，下次启动自动找回。
- 隐藏方式、快捷键、目标等设置自动保存在程序目录的 `bosskey.settings.json`。
- 可选开机自启。

## 构建

```powershell
dotnet build BossKey.csproj -c Release
dotnet publish BossKey.csproj -c Release -o publish
```
